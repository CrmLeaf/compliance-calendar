Notable changes to `crmleaf/compliance-calendar`.

Format per [Keep a Changelog](https://keepachangelog.com/en/1.1.0/); versioning
per [Semantic Versioning](https://semver.org/spec/v2.0.0.html) - with one extra
rule this package observes, because it computes statutory figures:

> **Any change that alters a published result is at minimum a minor release**,
> and is listed under `Changed` with the notification, circular or Act section
> that prompted it.

## [Unreleased]

## [1.0.0] - 2026-08-12

### Added

- Initial release. Expands the statutory recurrence rules into dated obligations for a financial year, so a 2019-20 calendar is generated by the same code as a 2026-27 one rather than typed out by hand.

### Statutory basis

- EPF Scheme 1952 para 38; ESI (General) Regulations 1950 regulation 31; Income-tax Rules 1962 rules 30, 31A and 31; CGST Rules 2017; the professional tax and labour welfare fund enactments of each state.
